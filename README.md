# AI UCP Control Panel — HTML-прототип

Многостраничный кликабельный прототип панели управления AI-агентами и сценариями.
Светлая корпоративная тема, зелёный акцент. Чистый HTML5 + CSS3 + JS, без сборки.

## Как открыть
Откройте `index.html` в браузере. Между экранами можно ходить через левое меню.
Библиотеки (Lucide, SortableJS) лежат локально в `assets/vendor/` — интернет не требуется.

## Стек
- Чистый CSS (`assets/app.css`) — дизайн-система и все UI-компоненты
- `assets/app.js` — оболочка (сайдбар, топбар), тосты, модалки, дропдауны, табы, lightbox
- Иконки: **Lucide**, drag-and-drop: **SortableJS**, шрифт: **Inter**

### Библиотека виджетов (изолированный слой)
`assets/widgets.css` + `assets/widgets.js` — самодостаточный UI-kit (токены `--k-*`, классы `.k-*`), не пересекается со стилями админки и подгружается отдельно. `widgets.js` инжектит SVG-спрайт, включает поведения (карусели, тоглы, степперы, билет, карта, месяц-календарь) и каталог `window.KWidgets` из 36 компонентов по 7 категориям — источник для реестра и конструкторов экрана. Среди компонентов: детальный календарь (месяц), лента дат, расписание со статусами (идёт / завершено / задержка / отменено), таблица, текстовый блок, плитки-показатели, баннер и уведомления-тосты, аккордион, заголовки и шаги сценария (прогресс + нумерованные шаги). Шаг «Показать экран» (`screen-step.html`) и мастер шага (`step-edit.html`) используют эти виджеты; экран собирается в макете телефона 393 px.

**Темы (светлая / тёмная).** Виджеты переключаются атрибутом `data-k-theme="dark"` на любом контейнере-предке. Переключатель «Светлая / Тёмная» есть в реестре виджетов и в обоих конструкторах экрана. **Светлая тема — исходная (mint/зелёный акцент), без изменений.** Вся перекраска — только внутри блока `[data-k-theme="dark"]`: тёмные поверхности + акцент **violet + teal** (акцент `--k-mint` → фиолетовый, свечение `#256D78`, акцентный градиент `#F5CCF7 → #4AA1A1`). Семантические цвета статусов (зелёный «идёт», жёлтый, красный) сохранены в обеих темах. Слой `widgets.css` самодостаточен: текст виджетов пин­уется на собственные токены `--k-*`, поэтому глобальные стили админки на него не влияют.

Настройки (`general-settings.html`) содержат вкладки **«Коннекторы»** (внешние агенты: OpenClaw, Hermes, собственные) и **«Поверхности»** (Telegram Bot + mini-app, Web app, Mobile app, Виджет).

## Что заложено
Статусная модель (running/ok/warn/error/idle), всплывающие тосты, модалки и drawer,
dropdown-меню, табы, стэппер, таймлайн, waterfall-трассировка, аттачи и изображения с
popup (lightbox), полный набор форм-контролов. Палитра графиков проверена на контраст и
цветовую слепоту.
